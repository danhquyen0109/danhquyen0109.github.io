## Graphics

`assets/thumb.svg` and `assets/thumb-tile.svg` are original SVGs written for this project

## Code

`index.html`, `style.css` and `game.js` are an original implementation. The sliding-tile
merge puzzle is a widely reimplemented rule set; no code, artwork or styling was copied
from any existing version — the palette deliberately follows this site's own teal/ink
scheme rather than any other game's look.
