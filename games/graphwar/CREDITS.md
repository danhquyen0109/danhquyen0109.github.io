## Code and name

`index.html`, `style.css` and `game.js` are an original implementation, including the
expression parser. No code, artwork or assets were taken from any existing game.

**Graphwar** is also the name of an existing freeware game that popularised this
"fire along y = f(x)" idea. This build shares only the concept — a genre premise, not a
protectable asset — but the name itself belongs to that project, so rename the folder and
title if this is ever published as a product rather than a personal demo.
